# Регресс по ролям (после visibility / аудита)

Проверить под каждой ролью: `ADMIN`, `RECRUITMENT_LEAD`, `RECRUITER`, `HR_BP`, `HIRING_MANAGER`, `SECURITY`.

## Кандидаты
- [ ] Список показывает только разрешённых кандидатов
- [ ] Открытие чужой карточки → 403/404, не данные
- [ ] Смена этапа доступна по правилам воронки
- [ ] Удаление только у ролей с правом

## Офферы и проверки
- [ ] Список офферов/проверок не показывает чужих кандидатов
- [ ] Одобрение/отклонение проверки с подтверждением
- [ ] Публичная ссылка проверки работает без логина

## MAX
- [ ] Диалоги фильтруются visibility
- [ ] Вложения исходящие/входящие
- [ ] Быстрые ответы подставляют текст
- [ ] Непрочитанные сбрасываются при открытии чата

## Auth
- [ ] 8+ неверных логинов → 429
- [ ] Logout сбрасывает refresh
- [ ] Истёкший refresh → «войдите снова»

## Админ
- [ ] Журнал `/audit` виден ADMIN/HR_BP/LEAD
- [ ] Отключение пользователя с подтверждением
